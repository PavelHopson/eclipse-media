# Бит-карта и план сцен

Рабочая поверхность «Бит-карта» превращает пользовательский аудиофайл в черновой монтажный план прямо в браузере.

## Основной поток

1. Пользователь подтверждает права на обработку файла.
2. Браузер локально декодирует аудио и строит огибающую энергии.
3. Анализатор оценивает темп, отмечает доли и делит материал на смысловые секции.
4. Для секций создаётся редактируемый план сцен.
5. Результат экспортируется как `eclipse.beat-map.v1` JSON.

В интерфейсе есть синтетический пример. Он позволяет проверить весь поток без загрузки пользовательского материала.

## Границы безопасности

- Аудио не отправляется в API и не сохраняется в браузерное хранилище.
- Принимаются только распространённые аудиоформаты размером до 60 МБ.
- Продолжительность ограничена 12 минутами, количество долей и сцен ограничено.
- Экспорт содержит метаданные анализа и план сцен, но не содержит исходное аудио.
- Для обработки требуется явное подтверждение прав на файл.

## Ограничения прототипа

Темп вычисляется эвристически по огибающей сигнала. Для сложного джаза, эмбиента, живых записей и треков с плавающим темпом результат является стартовой разметкой, а не мастер-анализом. Названия, планы и переходы можно исправить перед экспортом.
