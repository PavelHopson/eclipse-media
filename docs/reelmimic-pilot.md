# ReelMimic pilot for Eclipse Media

Статус: подготовка, без установки и без production-включения.

## Цель

Проверить, помогает ли ReelMimic разбирать **собственный короткий ролик** и переносить
ритм/раскадровку в Media. Пилот не копирует исходные кадры, персонажей, логотипы, музыку
или другие материалы третьих лиц.

## Ограничения

- Использовать только собственный или явно разрешённый ролик длительностью 30–60 секунд.
- Работать в отдельной копии проекта, без production secrets и пользовательских данных.
- Не включать автоматическую публикацию, социальные API, Upload-Post или cloud upload.
- Не подключать ReelMimic к Media runtime до завершения smoke, license review и manual review.
- Любой внешний API-key хранить только вне Git в локальном secrets-файле.

## Подготовка среды

Официальные требования ReelMimic: Node.js 22.18+, Python 3.10+, FFmpeg, Chrome и
вошедший Codex CLI или Claude Code.

Проверить установку в отдельной папке:

```bash
git clone https://github.com/edenfunf/reelmimic.git
cd reelmimic
./install.sh
cd app
npm run doctor
```

На Windows использовать `install.bat` и `start.bat`. До запуска проверить, что входной
ролик находится локально, путь не содержит секретов, а проект запускается на localhost.

## Сценарий пилота

1. Зафиксировать baseline: длительность, разрешение, число сцен, время ручного storyboard,
   количество правок и субъективную оценку режиссуры.
2. Передать ReelMimic собственный ролик и короткий brief без имён чужих авторов и брендов.
3. Проверить план до запуска производства: сцены, тайминги, переходы, палитра и камера.
4. Собрать одну 2D-сцену в выбранном движке.
5. Проверить результат вручную: playback, монтажные склейки, субтитры, артефакты и соответствие brief.
6. Сравнить с baseline: время, token usage, количество исправлений, повторяемость и качество review.
7. Зафиксировать решение: `integrate`, `reference` или `reject`.

## Критерии остановки

Пилот прекращается, если появляются неизвестные сетевые обращения, попытка использовать
чужие материалы, запись секретов в лог, неконтролируемая публикация, отсутствие исходных
прав или невозможность удалить все временные артефакты.

Результат пилота не считается production-функцией Media. Интеграция требует отдельного
изменения runtime, security review, browser/media QA и явного release approval.
