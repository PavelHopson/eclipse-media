# Переносимый проект разбора и сцен

Опубликовано 2026-09-06 в web-production, commit 5550f280d1117cbd92b9ce9ea70416a5861921a8. [Отчёт о релизе и проверках](tasks/2026-09-06-portable-project-file.md).

Формат v1 остаётся совместимым. В [«Моих проектах»](local-projects.md) импорт создаёт новый проект, а не заменяет текущий. При наличии общего сценария используется eclipse.media-project.v2 с прежними четырьмя корневыми полями и дополнительным beats.storyboard. [Текущая реализация и подтверждение публикации](tasks/2026-09-06-storyboard-projects.md).

## Что сохраняется

Кнопка «Скачать проект» создаёт локальный JSON с двумя рабочими разделами:

- полный загруженный текст субтитров, исходное имя файла и SHA-256, ссылка на видео, выбранные тезисы, поля проверки и текущая страница;
- бит-карта, сцены, заметки и незаконченная режиссура, выбранная сцена и введённая ссылка на согласие исполнителя.
- в v2 также общий сценарий: порядок, длительность, музыка, действие, камера, снимки связанных тезисов с исходным текстом, SHA-256 субтитров и таймкодами.

Это отдельный формат, а не прежние экспорты разбора, бит-карты или режиссуры. Прежние экспорты по-прежнему требуют завершённых полей и ручной проверки.

Не включены аудио/видео, очередь загрузок, медиатека, ссылки из intake-очереди, монтажные файлы, настройки автосохранения, серверные секреты и локальные ревизии хранилища. Реального наличия прав, истинности тезисов или согласия файл не доказывает.

## Контракт

Файл: eclipse-media-project-YYYY-MM-DD.json. UTF-8, не более 4 МиБ.

Корневые поля строго фиксированы:

- schema: eclipse.media-project.v1;
- exportedAt: ISO UTC timestamp с миллисекундами;
- research: ResearchDraft;
- beats: BeatDraft.

Схемы разделов и пределы находятся в frontend/src/services/draftContract.ts. Валидация повторно использует ограничения draft v1, включая лимит 2 МиБ для записи каждого раздела, точные ключи, последовательные ID и ссылки между заметками и сценами. Неизвестная версия, лишние поля, бинарные или повреждённые данные отклоняются. Частично заполненные поля допустимы.

JSON не зашифрован и содержит полный текст субтитров, а не только выбранные цитаты. Пользователь видит предупреждение перед скачиванием и может передать файл вручную доверенному получателю. При открытии нет сетевых запросов, выполнения инструкций из текста, автоматической загрузки исходного видео или публикации.

## Безопасное открытие в «Моих проектах»

1. Проверить расширение, размер, UTF-8, схему и все вложенные данные.
2. Показать содержимое по разделам и редактируемое название. Пользователь может отменить импорт.
3. После «Добавить и открыть» зарезервировать оба контроллера текущего проекта.
4. Сравнить ревизии каталога и изменённых черновиков. В одной IndexedDB-транзакции сохранить ожидающие правки прежнего проекта, два новых раздела и запись каталога с новым UUID.
5. Только после commit открыть новый проект и сбросить временные состояния прежних импортов. Прежний проект остаётся в списке.

Отказ второй записи или конфликт другой вкладки отменяет всю операцию. Частичного проекта в каталоге не возникает. Старые autosave-таймеры всегда привязаны к своему project ID и не могут перезаписать импортированный проект. При неудаче они возобновляются для прежней работы.

Настройки автосохранения локальны для раздела проекта: новый проект наследует их от текущего, импорт их не включает. Для выключенного раздела на диске сохраняется только пустая tombstone-запись, содержимое открывается в памяти. Если оба раздела работают без доступного хранилища, открытие и скачивание тоже доступны без записи в IndexedDB. Название и UUID не добавлены в переносимый v1 JSON: при импорте название предлагается из имени файла и редактируется пользователем.

## Проверки

- npm --prefix frontend test: формат, неполные поля, каталог, миграция, квота, атомарность, параллельные операции и memory-only. Внутренний legacy-coordinator замены по-прежнему имеет отдельные тесты, но не используется интерфейсом «Открыть проект».
- node scripts/qa-local-projects.cjs (также доступен через прежнюю команду qa-project-files.cjs): отдельные профили Edge, создание/переименование/копирование/переключение, перенос через скачанный файл, отмена/Escape/Tab, размеры 1440/390/320, повреждённый UTF-8, XSS-текст как данные, ошибка второй записи, конфликты вкладок и режим без хранилища.
- node scripts/qa-local-drafts.cjs: регрессия автосохранения.

Browser QA требует ANURA_PLAYWRIGHT_PATH, ANURA_BROWSER_PATH и локальный preview на 127.0.0.1:4192. После разрешения публикации ECLIPSE_MEDIA_QA_BASE можно явно задать как https://media.eclipse-forge.ru. Другие адреса отклоняются; внешние запросы и серверные мутации блокируются. Production-проверка использует отдельные тестовые профили и синтетические данные.
