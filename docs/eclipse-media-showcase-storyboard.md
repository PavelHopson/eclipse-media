# Eclipse Media showcase storyboard

Статус: draft для локального рендера. Публикация видео не выполняется автоматически.

## Задача

Показать главный путь Eclipse Media за 45–60 секунд:

**источник → проверка прав → план → обработка → review → готовый медиафайл**

Ролик демонстрирует собственный интерфейс и локальные assets. Чужие ролики, бренды,
логотипы и музыку без разрешения не используем.

## Визуальный контракт

- Тёмная Eclipse Forge палитра.
- Золотой акцент для главного действия.
- Сигнальный синий для прогресса и системных состояний.
- Самостоятельные UI-переходы на `transform`/opacity.
- Без бесконечной анимации и без motion при `prefers-reduced-motion`.
- Форматы: 16:9 master, затем 9:16 и 1:1 из той же раскадровки.
- Музыка: собственная или public-domain; допускается тихий UI sound design.

## Сцены

### 01 — Источник · 0–8 с

Крупный план Media Intake. Пользователь вставляет разрешённую ссылку,
выбирает цель «Подготовить видео» и видит короткую проверку источника.

**Текст:** «Один источник. Понятная цель.»

### 02 — Права · 8–16 с

Появляется rights gate. Подтверждение прав подсвечивается золотым акцентом,
неподтверждённые действия остаются заблокированными.

**Текст:** «Сначала права, потом обработка.»

### 03 — Очередь · 16–26 с

В очередь добавляется проект. Видны стадии `preparing`, `downloading`,
`processing`, `finalizing`; прогресс не показывает ложные 100%.

**Текст:** «Статус виден на каждом шаге.»

### 04 — План сцен · 26–37 с

Открывается план: сцены, таймкоды, камера, субтитры и заметки.
Переход к video studio выполняется без публикации.

**Текст:** «Из материала — в рабочий план.»

### 05 — Review · 37–49 с

Показывается preview, waveform и subtitle track. Пользователь отмечает
один момент и запускает повторную проверку.

**Текст:** «Проверка остаётся у человека.»

### 06 — Результат · 49–60 с

Готовый MP4 получает receipt, checksum и понятное действие сохранения.
Финальный экран — Eclipse Media и CTA «Открыть мастерскую».

**Текст:** «Готово к следующему шагу.»

## Критерии готовности

- Все шесть сцен читаются без звука.
- Текст не выходит за safe zones в 16:9, 9:16 и 1:1.
- Нет сетевых запросов к внешним медиа во время preview.
- Нет реальных пользовательских ссылок, cookies, токенов и локальных путей в кадре.
- В ролике явно показано, что публикация остаётся ручным действием.
- После рендера пройти playback, декодирование, subtitle timing и visual QA.
