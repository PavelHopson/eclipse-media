# Первые 3 секунды — локальные зацепки

Реализация 2026-09-11: `frontend/src/components/ShortVideoHooks.tsx`, контракт `shortVideoHooks.ts`.

Маршрут: Сценарий проекта → Первые 3 секунды ролика → четыре поля → шесть заготовок → три редактируемых слоя → review → новая первая сцена. Детерминированные шаблоны, не вызов модели. Генерации видео и списаний нет.

Сцена сохраняется штатным DraftController и входит в project v2 JSON. Заготовка до вставки остаётся в памяти компонента. При переключении проекта компонент размонтируется по storageKey. Лимит 24 сцены сохранён. Добавление и отмена используют актуальный controller state, не старую копию массива. Отмена не удаляет изменённую сцену. Изменение зацепки сбрасывает review.

Валидация: ограниченные строки, служебные/bidi символы и известные признаки секретов отклоняются. Это не универсальный DLP; вводить секреты всё равно нельзя. React выводит текст без HTML-интерпретации. Новых URL-запросов, зависимостей, API и разрешений нет.

Проверки: `npm run typecheck`, `npm test`, `npm run build` в frontend; браузерный сценарий `../eclipse-ai-hub/scripts/qa-skills-workflows.cjs` использует два локальных dev-сервера, синтетические данные и одноразовые профили Edge. Итоговые результаты и статус — в общей задаче `2026-09-11-skills-workflows.md` EclipseForgeLanding. Production не менялся.
